# New Stylish Tailors Boutique

Nine-page static HTML, CSS and JavaScript website for the Jadavpur boutique, published on GitHub Pages from `main` / root.

Pages: Home, Our Boutique, Explore, Salwar Suits, Kurtis, Sarees, Gallery, FAQ, Contact.

The genuine earlier interior photograph is the hero. Category illustrations are explicitly identified; no image implies current stock. Research, identity checks, image sources, illustration prompts and factual conflicts: [docs/SOURCES.md](docs/SOURCES.md).

Responsive at phone, tablet, laptop and desktop widths. Keyboard navigation, focus indicators, mobile menu, native FAQ controls, click-to-call, copy-address status, reduced-motion support. No tracking, payment collection, fake booking form or server dependencies.

The layered visual design includes perspective photo frames, translucent lighting surfaces, floating captions, depth shadows, staggered entrances, scroll reveals, subtle scroll depth, pointer-responsive category cards and page transitions. Motion is disabled for reduced-motion preferences.

Each page has one H1, a unique title/description, canonical and Open Graph tags, verified-detail JSON-LD and the separate business copyright and Cloudempire credit. `sitemap.xml`, `robots.txt` and `.nojekyll` are included.

Preview: `python -m http.server 8765` from the repository directory. No framework or build tool is needed.
